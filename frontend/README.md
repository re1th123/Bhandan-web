# Bandhan ERP — Frontend Web Application

This directory contains the **React 18 + TypeScript + Vite + Material UI (M3)** frontend application for **Bandhan ERP**.

---

## 🚀 Key Modules Built

* 📈 **Sales Dashboard** (`src/pages/sales/SalesDashboardPage.tsx`) — Real-time revenue KPIs, customer receivables aging, target progress gauge, top products, payment channel distribution, filter drawer, and Speed Dial FAB.
* 📦 **Inventory Dashboard** (`src/pages/inventory/InventoryDashboardPage.tsx`) — Stock command center, warehouse capacity meters, inventory health gauges, dead stock trapped capital analysis, physical count variance audits, and replenishment recommendations.
* 🛍️ **Purchase Dashboard** (`src/pages/purchases/PurchaseDashboardPage.tsx`) — Procurement command center, open PO delivery tracking, un-invoiced GRNs, supplier payables aging, cost fluctuation analytics, and automated PO generation.

---

## 🛠️ Build & Scripts

* **Dev Server**: `npm run dev`
* **Production Build**: `npm run build`
* **Preview Build**: `npm run preview`
